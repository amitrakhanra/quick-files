FAQ

Are my files uploaded anywhere?

Files are processed locally in your browser and are not intentionally uploaded by QuickFile. Processing libraries are downloaded from cdnjs when needed. Avoid using this site for highly sensitive documents on shared or untrusted devices.

Are the tools free?

Yes, free with no sign-up.

Why do Strong compress, Unlock and Lock PDF turn text into images?

Those modes redraw each page as an image in your browser, which gives smaller files and removes restrictions, but text is no longer selectable.

How good is PDF to Word?

It extracts text only. Tables, columns and images are not reproduced, and scanned PDFs without real text are not supported.

Found a bug or want a new tool?

Email us at QuickfilesV1.1@gmail.com. If a tool shows an error, include the message and the tool name.

Processing limits

To protect browser stability, this version limits individual files to 100 MB, combined selections to 200 MB, PDF rendering to 250 pages at a time, and resized images to 40 megapixels. Some older browsers or low-memory devices may have lower practical limits.

About Resize Image

Change the width and height of one image or many at once. You can set exact pixel sizes, or scale by a percentage, such as 50% for half the size.

With Keep aspect ratio ticked, the picture is never stretched: give a width or a height and the other side follows, or give both and the image fits inside that box. PNG and WebP images stay in their format and everything else is saved as JPG.

How to resize an image

  1. Choose one or more images.
  2. Type a width, a height, or a percentage.
  3. Leave Keep aspect ratio ticked unless you want to stretch the picture.
  4. Click Resize. One image downloads, or several download as a ZIP.

Tips and limits

  • Making an image smaller in pixels also makes the file smaller, but this is not the same as setting a file size. For a KB limit use Compress Image to a Specific Size.
  • Enlarging a small picture makes it blurry. It cannot add detail that is not there.
  • Output is limited to 40 megapixels to keep your browser stable.

Frequently asked questions

Can I resize many images at once?

Yes. Add them all, set the size once, and they are all resized with the same settings.

Will it keep the shape of my picture?

Yes, while Keep aspect ratio is ticked. Untick it only if you want an exact width and height even if that stretches the picture.

Does it change the file format?

PNG stays PNG and WebP stays WebP. Other formats such as JPG, GIF and BMP are saved as JPG.

Is it private?

Your file is opened and processed by JavaScript running in your browser, and QuickFile does not upload it. The processing libraries are downloaded from cdnjs the first time a tool needs them. Read the full details in our privacy policy.
