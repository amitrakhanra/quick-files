FAQ

Are my files uploaded anywhere?

Files are processed locally in your browser and are not intentionally uploaded by QuickFile. Processing libraries are downloaded from cdnjs when needed. Avoid using this site for highly sensitive documents on shared or untrusted devices.

Are the tools free?

Yes, free with no sign-up.

Why do Strong compress, Unlock and Lock PDF turn text into images?

Those modes redraw each page as an image in your browser, which gives smaller files and removes restrictions, but text is no longer selectable.

How good is PDF to Word?

It extracts text only. Tables, columns and images are not reproduced, and scanned PDFs without real text are not supported.

Found a bug or want a new tool?

Email us at QuickfilesV1.1@gmail.com. If a tool shows an error, include the message and the tool name.

Processing limits

To protect browser stability, this version limits individual files to 100 MB, combined selections to 200 MB, PDF rendering to 250 pages at a time, and resized images to 40 megapixels. Some older browsers or low-memory devices may have lower practical limits.

About Compress PDF

Make a PDF smaller so it is easier to email or upload. There are two levels, because a PDF can be shrunk in two very different ways.

Light mode re-saves the file in a more compact form and keeps the text selectable, but savings are usually small. Strong mode redraws every page as an image, which can shrink scans and photo-heavy PDFs a lot, but the text is no longer selectable. After each run QuickFile shows the size before and after.

How to compress a PDF

  1. Choose your PDF or drop it onto the box.
  2. Pick Light (keeps text selectable) or Strong (pages become images).
  3. Click Compress. The sizes before and after are shown.
  4. If the new file is smaller it downloads. Otherwise nothing is downloaded.

Tips and limits

  • Strong mode works best on scanned or photo-heavy PDFs. On a mostly-text PDF it can make the file bigger, in which case nothing is downloaded.
  • If you need an exact limit such as 200 KB, use Compress PDF to a Specific Size.
  • Keep your original file. Strong mode cannot be undone.

Frequently asked questions

Why did my file not get smaller?

Many PDFs are already compact. When the result would not be smaller, QuickFile tells you and does not download it, so you never get a bigger file by accident.

Is the text still selectable after compressing?

In Light mode yes. In Strong mode no, because pages are saved as images.

Can I compress to an exact size like 100 KB?

Yes. Use Compress PDF to 100 KB, or Compress PDF to a Specific Size to type your own limit.

Is it private?

Your file is opened and processed by JavaScript running in your browser, and QuickFile does not upload it. The processing libraries are downloaded from cdnjs the first time a tool needs them. Read the full details in our privacy policy.
