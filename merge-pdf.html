FAQ

Are my files uploaded anywhere?

Files are processed locally in your browser and are not intentionally uploaded by QuickFile. Processing libraries are downloaded from cdnjs when needed. Avoid using this site for highly sensitive documents on shared or untrusted devices.

Are the tools free?

Yes, free with no sign-up.

Why do Strong compress, Unlock and Lock PDF turn text into images?

Those modes redraw each page as an image in your browser, which gives smaller files and removes restrictions, but text is no longer selectable.

How good is PDF to Word?

It extracts text only. Tables, columns and images are not reproduced, and scanned PDFs without real text are not supported.

Found a bug or want a new tool?

Email us at QuickfilesV1.1@gmail.com. If a tool shows an error, include the message and the tool name.

Processing limits

To protect browser stability, this version limits individual files to 100 MB, combined selections to 200 MB, PDF rendering to 250 pages at a time, and resized images to 40 megapixels. Some older browsers or low-memory devices may have lower practical limits.

About Merge PDF

Join two or more PDFs into one document. Typical uses are combining a cover page with an assignment, putting scanned pages together, or sending one file instead of several.

Add the PDFs, arrange them with the ↑ and ↓ buttons, and QuickFile joins them in exactly that order. Pages are copied as they are, so text stays selectable and nothing is turned into an image.

How to merge PDF files

  1. Choose at least two PDF files, or drop them onto the box.
  2. Use ↑ and ↓ to set the order. The first file in the list comes first.
  3. Click Merge PDFs.
  4. Your combined file quickfile-merged.pdf downloads.

Tips and limits

  • The combined PDF can have up to 250 pages in this version.
  • If one file is password-protected, remove its password with Unlock PDF before merging.
  • Merging can make a large file. Use Compress PDF afterwards if you have a size limit.

Frequently asked questions

Does merging change the pages?

No. Pages are copied across as they are, in the order you chose, so text stays selectable.

How many PDFs can I merge?

There is no fixed number of files, but each file can be up to 100 MB, the total up to 200 MB, and the result up to 250 pages.

Can I merge only some pages?

Yes. First use Split PDF to extract the pages you need, then merge the results.

Is it private?

Your file is opened and processed by JavaScript running in your browser, and QuickFile does not upload it. The processing libraries are downloaded from cdnjs the first time a tool needs them. Read the full details in our privacy policy.
